イラスト

裏帯の後ろ。帯の上端で切れる
表帯の前。帯にはみ出せる

1枚だけなら「裏」に入れます。プレビューへのドロップでも入れられます。背景を透過したPNGがおすすめです。

プレビューをドラッグで移動。スマホは2本指で拡大縮小。裏と表は同じ位置・大きさで一緒に動きます。「差し替え」をしても位置と大きさはそのままです。

色

色を個別に選ぶ

上の「ベース」「背景」で、変える方を選んでから色を押します。

日曜・祝日は赤、土曜は青。背景と近くて読めないときはベースの色のままにします。

書体

書体を変えると、数字の高さと位置は自動で揃えます。気になるときは大きさと字間で手直しできます（書体を変えると元に戻ります）。

クレジット

前に使ったクレジット（書き出したときに覚えます）

書き出し

ファイルの形式

回転アニメ（GIF・動画）

スマホが上下にゆれながら、いちばん下でくるっと1回転して次の待受に切り替わるアニメを作ります。月やイラストを変えるたびに追加して並べてください（1枚だけなら回らずにゆれます）。

背景

透過の GIF は、影やスマホの縁の半透明を細かい点で表します。透過の動画は WebM で書き出します（MP4 は透過を持てません）。

GIF は 600 がおすすめです（大きいとファイルが重くなります）。動画は MP4、ブラウザによっては WebM になります。
